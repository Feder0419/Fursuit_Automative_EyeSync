## Some thoughts:
1. About how to detect the viewers' motion:
    I've spotted someone at furry con put a phone in his fursuit chest pocket, with camera facing the viewers (probably for recording). Perhaps we can also use a phone and an app with camera to detect viewers' motion. Extensively, we can put a lot of calculation into app, so the electronic components in fursuit only need to do minimum calculation and will have better battery life. I've also find out that the LED eye of Beast-Fantasy's fursuit is also controlled by cell phone app. Though I doubt its practicallity, since it's hard to wield cell phone when wearing suit.
2. As for control methods: 
    Since controlling via phone is not very practical. I was thinking about the controlling method of apple watch. Tapping two fingers can call out some function on apple watch. Perhaps we can also use such body motion to control (like shuffling eye pattern). Another much easier method would be to attach some physical small button or switches inside fursuit.
3. A further question for the first two question:
    Given these two questions, should we adjust our previous logical topology? Maybe we could put a lot of calculation and function inside an app, to minimize the components inside suit. But I'm afraid of the stability of wireless control. The last thing we want would be the LED eye just lost connection and freeze.
4. The project itself would be not much of a challenge, if the space inside the suit is as large as we want. But given the space is limited, 
    how to minimize calculation and not affect suit's "wearability" is a major concern.
5. Some DLC function?:
    It would be cool if we add a VR set or anything else to improve visibility inside suit. Last time I wear a suit, I can barely see who is in front of me, so it's very difficult to know who is talking to me.
6. I'm thinking about perhaps we should develop in iteration. Implement the basic function first, and then add each component to the set. We
    can even extend more advance function if previous function is successful.
